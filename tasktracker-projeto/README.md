# TaskTracker

Aplicacao de linha de comando em Python para cadastrar e visualizar tarefas.

# Funcionalidades
 Cadastro de tarefas com titulo, descricao, prioridade e data limite.
 Validacao para impedir titulo vazio.
 Validacao de prioridade: Alta, Média/Media ou Baixa.
 Status inicial automatico: Pendente.
 Listagem das tarefas cadastradas e mensagem para lista vazia.

## Como executar
No terminal, na pasta raiz do projeto:

```bash
python src/main.py
```
